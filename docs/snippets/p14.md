## 镜 11 · 几种常用断言（P14 03:28）

归类：教学摘录，非完整程序。

> 测试函数也可以返回 Result，返回 Err 即视为失败，此时可用 ?。

```rust
assert!(rect.width > 0, "宽度必须为正：{:?}", rect);

#[test]
#[should_panic(expected = "下标越界")]
fn should_fail() {
    Guess::new(200);
}

#[test]
fn it_works() -> Result<(), String> {
    if 2 + 2 == 4 { Ok(()) } else { Err(String::from("算错了")) }
}
```

## 镜 18 · tests/ 下的独立 crate（P14 05:41）

归类：教学摘录，非完整程序。

> 二进制项目（只有 main.rs）没法被外部 use，业务逻辑应放进 lib.rs。

```rust
// tests/integration_test.rs
use adder::add_two;

#[test]
fn it_adds_two() {
    assert_eq!(add_two(2), 4);
}

// 只跑某一个集成测试文件
$ cargo test --test integration_test
```

## 镜 21 · 常用命令行参数（P14 06:34）

归类：命令行示例。

> 注意 -- 之后的参数是传给测试二进制的，不是给 Cargo 的。

```bash
$ cargo test                       # 全部
$ cargo test add_two               # 名字过滤
$ cargo test -- --nocapture        # 显示打印
$ cargo test -- --test-threads=1   # 单线程
$ cargo test -- --ignored          # 只跑被忽略的
```
