## 每篇的固定结构

导语（为什么难 + 视频定位）→ 3–5 个递进小节 → 常见坑 → 配套资源表（视频时间点、可运行示例与 `cargo run` 命令、故意报错反例与错误码）→ 小结与引导。

## 发布建议

1. 每篇开头嵌对应视频卡片，结尾放配套代码仓库链接，形成「文章 → 视频 → 代码」闭环。
2. 按 P05 → P06/P13 → P11 → P12 → P19 → P20 的顺序发，与视频合集进度错开，不要一次性发完。
3. 文章里的代码块可直接复制；贴出的片段均逐字取自仓库文件，运行命令已在 README 的校验流程中覆盖。
4. 异步篇涉及 tokio / futures 的片段保留在 `docs/snippets/p20.md`，仓库本身只提供纯标准库示例，文章里已如实注明，转载时请保留这一说明。

## 一致性说明

6 篇文章中所有 `pNN_sNN.rs` 引用、`cargo run -p chNN --example ...` 命令、`E0xxx` 错误码与 `Pxx mm:ss` 视频时间点均已逐项核对，与 `tools/entries.json`、`publish.csv` 和磁盘文件一致。内容依据《Rust 程序设计语言 简体中文版》(MIT) 与 rust-lang/book (Apache-2.0 / MIT) 改编，署名见仓库 `NOTICE.md`。
