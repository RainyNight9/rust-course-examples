## 镜 17 · channel + Arc&lt;Mutex&gt;（P22 04:47）

归类：教学摘录，非完整程序。

> FnOnce + Send + 'static：任务只跑一次、能跨线程转移、不借用短命数据。

```rust
pub struct ThreadPool {
    workers: Vec<Worker>,
    sender: Option<mpsc::Sender<Job>>,
}

type Job = Box<dyn FnOnce() + Send + 'static>;

impl ThreadPool {
    pub fn execute<F>(&self, f: F)
    where F: FnOnce() + Send + 'static {
        let job = Box::new(f);
        self.sender.as_ref().unwrap().send(job).unwrap();
    }
}
```

## 镜 20 · Drop 里通知并等待（P22 05:33）

归类：教学摘录，非完整程序。

> 先用 Option::take() 拿走所有权，才能在 &amp;mut self 里移动字段。

```rust
impl Drop for ThreadPool {
    fn drop(&mut self) {
        drop(self.sender.take());
        for worker in &mut self.workers {
            if let Some(thread) = worker.thread.take() {
                thread.join().unwrap();
            }
        }
    }
}
```

## 镜 21 · 先 drop(sender) 再join（P22 05:45）

归类：教学摘录，非完整程序。

> 先关通道让 recv 返回 Err、worker 退出循环，再 join；Option::take() 才能在 &mut self 里移动字段。

```rust
impl Drop for ThreadPool {
    fn drop(&mut self) {
        // 少了 drop(self.sender.take()); —— 通道不关闭，worker 永远等不到结束
        for worker in &mut self.workers {
            if let Some(t) = worker.thread.take() {
                t.join().unwrap();   // 会一直卡在这里
            }
        }
    }
}
```
