## 镜 04 · 把五步装进一个 main（P03 01:12）

归类：需第三方依赖。

> 注意 secret: u32 和 parse 出的 u32 类型一致，cmp 才能比较。

```rust
use rand::Rng;
use std::cmp::Ordering;
use std::io;

fn main() {
    let secret: u32 = rand::thread_rng().gen_range(1..=100);
    loop {
        println!("猜一个 1 到 100 的数字：");
        let mut guess = String::new();
        io::stdin()
            .read_line(&mut guess)
            .expect("读取失败");
        let guess: u32 = match guess.trim().parse() {
            Ok(num) => num,
            Err(_) => continue,
        };
        match guess.cmp(&secret) {
            Ordering::Less => println!("太小"),
            Ordering::Greater => println!("太大"),
            Ordering::Equal => {
                println!("猜中");
                break;
            }
        }
    }
}
```

## 镜 09 · Cargo.toml 加一行就行（P03 02:49）

归类：配置 / 输出片段。

> 1..=100 是包含端点的范围；trait 必须引入作用域，方法才可用。

```toml
# Cargo.toml
[dependencies]
rand = "0.8"

// src/main.rs
use rand::Rng;

let secret_number = rand::thread_rng().gen_range(1..=100);
```

## 镜 10 · rand 的 API 随版本变（P03 03:05）

归类：配置 / 输出片段。

> 0.8 用 thread_rng + gen_range；use rand::Rng 必须引入 trait 方法才可见。

```toml
// Cargo.toml 里: rand = "0.8"
use rand::Rng;

fn main() {
    let mut rng = rand::thread_rng();
    let n: u32 = rng.gen_range(1..=100);
    let m: u32 = rng.gen_range(50..=60);
    println!("{n} {m}");
}
```

## 镜 20 · continue 跳的是整个 loop（P03 06:10）

归类：教学摘录，非完整程序。

> continue 回到 loop 顶部；换成 break 会直接结束游戏。

```rust
// 以下是 loop 循环体里的片段
let guess: u32 = match guess.trim().parse() {
    Ok(num) => num,
    Err(_) => continue,
};
// 只有解析成功才会走到这里
println!("你猜的是 {guess}");
```
