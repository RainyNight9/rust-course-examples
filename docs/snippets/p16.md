## 镜 18 · collect / sum / find（P16 05:19）

归类：教学摘录，非完整程序。

> collect 常需要类型标注，编译器无法从上下文推断要收成哪种集合。

```rust
let total: i32 = v.iter().sum();

let names: Vec<String> = lines.iter()
    .map(|l| l.to_uppercase())
    .collect();

if let Some(found) = v.iter().find(|&&x| x == 3) {
    println!("找到 {found}");
}
```

## 镜 21 · 零成本不是口号（P16 06:13）

归类：教学摘录，非完整程序。

> impl Iterator 作参数，直接接收 env::args()，不再 collect 成 Vec。

```rust
impl Config {
    fn build(mut args: impl Iterator<Item = String>)
        -> Result<Config, &'static str>
    {
        args.next();   // 跳过程序名
        let query = args.next().ok_or("缺少查询词")?;
        let file_path = args.next().ok_or("缺少文件路径")?;
        Ok(Config { query, file_path,
                    ignore_case: env::var("CASE_INSENSITIVE").is_ok() })
    }
}
```
