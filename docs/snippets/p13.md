## 镜 08 · &'a str 读成什么（P13 02:26）

归类：教学摘录，非完整程序。

> 'a 读作「生命周期 a」，写在 &amp; 之后、类型之前。

```rust
&i32          // 普通引用
&'a i32       // 带显式生命周期的引用
&'a mut i32   // 带生命周期的可变引用
```

## 镜 11 · 告诉编译器返回值跟谁一样久（P13 03:25）

归类：教学摘录，非完整程序。

> 约束的是输出结果的有效范围，不是给变量续命。

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}

let result;
{
    let s2 = String::from("xyz");
    result = longest(&s1, &s2);
}   // s2 已失效，result 的生命周期到此为止
```
