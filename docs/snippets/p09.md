# P09 · 包、Crate 与模块 — 讲解摘录

对应 第 7 章 模块系统。以下片段按视频顺序保留原样，
它们是命令行、配置、控制台输出、第三方依赖示例或教学语句摘录，**不是可独立编译的程序**。

## 镜 04 · 把 crate 根钉死（P09 01:12）

归类：配置 / 输出片段。

> 一个包由 Cargo.toml 定义，src/lib.rs 是库 crate 的根。

```toml
# Cargo.toml
[package]
name = "restaurant"
version = "0.1.0"
edition = "2024"

// src/lib.rs —— 库 crate 的根，模块树从这里长出来
pub fn add(left: u64, right: u64) -> u64 {
    left + right
}
```

## 镜 07 · 从 crate 根长出来（P09 01:54）

归类：教学摘录，非完整程序。

> 模块默认私有：父子之间可见性规则不同，外部访问需要 pub。

```rust
mod front_of_house {
    mod hosting {
        fn add_to_waitlist() {}
    }
}

// 绝对路径
crate::front_of_house::hosting::add_to_waitlist();
// 相对路径
front_of_house::hosting::add_to_waitlist();
```

## 镜 10 · pub 只打开一层（P09 02:43）

归类：教学摘录，非完整程序。

> pub struct 只让类型公开，字段要单独写 pub 才能从外部构造。

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist();
}
```

## 镜 13 · 给路径起个短名（P09 03:33）

归类：教学摘录，非完整程序。

> 同名类型可以用 as 起别名：use std::io::Result as IoResult;

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist();
}

use std::collections::HashMap;
let mut map = HashMap::new();
```

## 镜 18 · mod xxx; 找同名文件（P09 04:58）

归类：配置 / 输出片段。

> 文件树和模块树一一对应；src/main.rs 与 src/lib.rs 可以同时存在。

```toml
// src/lib.rs
mod front_of_house;
pub use crate::front_of_house::hosting;

// src/front_of_house.rs
pub mod hosting;

// src/front_of_house/hosting.rs
pub fn add_to_waitlist() {}
```

## 镜 21 · 依赖也在模块树里（P09 05:49）

归类：配置 / 输出片段。

> 工作空间 workspace 可以管理多个包，第 14 章会展开。

```toml
# Cargo.toml
[dependencies]
rand = "0.8"

// src/main.rs
use rand::Rng;
let n = rand::thread_rng().gen_range(1..=100);
```
