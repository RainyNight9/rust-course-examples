## 镜 11 · join 返回 Result（P19 03:05）

归类：教学摘录，非完整程序。

> 把 join 的位置往前挪或往后挪，就能观察两个线程输出如何交错。

```rust
let handle = thread::spawn(|| {
    for i in 1..5 { println!("hi {i}"); }
});

handle.join().unwrap();   // 等它跑完再继续
```

## 镜 13 · clone tx 就行（P19 03:35）

归类：教学摘录，非完整程序。

> 注意最后要 drop(tx)，否则接收端会一直等下去。

```rust
let tx1 = tx.clone();
thread::spawn(move || {
    for val in vec![1, 2, 3] { tx1.send(val).unwrap(); }
});
thread::spawn(move || {
    for val in vec![4, 5] { tx.send(val).unwrap(); }
});
drop(tx);

for received in rx { println!("{received}"); }
```
