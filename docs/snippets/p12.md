## 镜 16 · impl Trait for Type（P12 04:17）

归类：教学摘录，非完整程序。

> 这条叫孤儿规则，保证不同 crate 不会给同一个类型实现同名 trait 而冲突。

```rust
pub struct NewsArticle { pub headline: String }

impl Summary for NewsArticle {
    fn summarize(&self) -> String {
        format!("{}", self.headline)
    }
}

let article = NewsArticle { headline: String::from("Rust 1.98 发布") };
article.summarize();
```

## 镜 18 · 约束写在哪里（P12 04:47）

归类：教学摘录，非完整程序。

> impl Trait 适合简单场景；多参数、多重约束时用泛型更清楚。

```rust
pub fn notify(item: &impl Summary) {
    println!("{}", item.summarize());
}

// 等价的 trait bound 写法
pub fn notify<T: Summary>(item: &T) { /* ... */ }

// 两个参数必须是同一类型
pub fn pair<T: Summary>(a: &T, b: &T) {}
```
