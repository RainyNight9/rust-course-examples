## 镜 06 · 和 mut 不是一回事（P04 01:45）

归类：教学摘录，非完整程序。

> 遮蔽会创建新变量，旧值被覆盖；mut 是在同一块内存上改值。

```rust
let spaces = "   ";
let spaces = spaces.len();   // 类型从 &str 变成 usize

let guess: u32 = guess.trim().parse().expect("数字");
```

## 镜 17 · 一个分号改变语义（P04 05:00）

归类：教学摘录，非完整程序。

> 错误：expected i32, found ()。块表达式 {} 的最后一行同理。

```rust
fn ok() -> i32 {
    5          // 表达式 → 返回 5
}

fn broken() -> i32 {
    5;         // 语句 → 返回 ()
}
```

## 镜 20 · if / loop / while / for（P04 05:58）

归类：教学摘录，非完整程序。

> if 是表达式，所以可以直接给 let 赋值，两个分支类型必须一致。

```rust
let n = if condition { 5 } else { 6 };

let mut counter = 0;
let result = loop {
    counter += 1;
    if counter == 10 { break counter * 2; }
};

for i in (1..4).rev() { println!("{i}"); }
```
