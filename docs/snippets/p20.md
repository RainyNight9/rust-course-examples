# P20 · async、await 与 Future — 讲解摘录

对应 第 17 章 异步编程。以下片段按视频顺序保留原样，
它们是命令行、配置、控制台输出、第三方依赖示例或教学语句摘录，**不是可独立编译的程序**。

## 镜 04 · #[tokio::main] 做了什么（P20 01:11）

归类：需第三方依赖。

> 依赖：Cargo.toml 加 tokio = { version = "1", features = ["macros", "rt-multi-thread"] }；该宏展开成运行时 + block_on。

```rust
#[tokio::main]
async fn main() {
    let v = async { 40 + 2 }.await;
    println!("{v}");
}
```

## 镜 06 · async fn 返回一个 future（P20 01:42）

归类：教学摘录，非完整程序。

> 返回值可能是 Poll::Pending（还没好）或 Poll::Ready(T)（完成）。

```rust
async fn fetch_data() -> String {
    String::from("数据")
}

pub trait Future {
    type Output;
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>)
        -> Poll<Self::Output>;
}
```

## 镜 09 · future 得有人推进（P20 02:27）

归类：需第三方依赖。

> 注意 future 是惰性的：不 await、不交给运行时，它一步都不会执行。

```rust
#[tokio::main]
async fn main() {
    let data = fetch_data().await;
    println!("{data}");
}
```

## 镜 10 · 不 await 就不打印（P20 02:42）

归类：需第三方依赖。

> 依赖：tokio 1.x 开启 macros 与 rt-multi-thread；去掉 .await，第一句 println! 永不输出。

```rust
#[tokio::main]
async fn main() {
    let fut = async {
        println!("这行会被打印吗？");
        7
    };
    println!("只构造了 future，还没推进");
    let v = fut.await; // 到这一步函数体才执行
    println!("拿到 {v}");
}
```

## 镜 12 · join! 而不是排队 await（P20 03:17）

归类：需第三方依赖。

> try_join! 用于返回 Result 的 future，任一出错就提前返回。

```rust
async fn a() -> u32 { 1 }
async fn b() -> u32 { 2 }

// 串行：总耗时 = a + b
let x = a().await;
let y = b().await;

// 并发：总耗时 ≈ max(a, b)
let (x, y) = tokio::join!(a(), b());
```

## 镜 13 · 超时会丢掉另一半（P20 03:30）

归类：需第三方依赖。

> 依赖：tokio 1.x 开启 macros / rt / time；落选分支被取消，未完成的状态要能安全丢弃。

```rust
use tokio::time::{sleep, timeout, Duration};

async fn write_all() {
    sleep(Duration::from_millis(50)).await;
    println!("写完了");
}

#[tokio::main]
async fn main() {
    // 10ms 就超时，write_all 在 .await 处被 drop，println! 不会执行
    let _ = timeout(Duration::from_millis(10), write_all()).await;
}
```

## 镜 15 · join_all 与 FuturesUnordered（P20 04:10）

归类：需第三方依赖。

> join_all 要等全部完成；FuturesUnordered 是完成一个就交出一个。

```rust
use futures::future::join_all;

let futs: Vec<_> = urls.iter().map(|u| fetch(u)).collect();
let results = join_all(futs).await;

use futures::stream::{FuturesUnordered, StreamExt};
let mut tasks = FuturesUnordered::new();
while let Some(result) = tasks.next().await {
    handle(result);
}
```

## 镜 16 · 一连串的 Future（P20 04:23）

归类：需第三方依赖。

> 网络分块到达、消息队列消费、定时事件，都很适合用 Stream 建模。

```rust
use futures::stream::{self, StreamExt};

let mut st = stream::iter(1..=3).map(|x| async move { x * 2 });
while let Some(v) = st.next().await {
    println!("{v}");
}
```

## 镜 18 · buffer_unordered 限并发（P20 04:51）

归类：需第三方依赖。

> 依赖：futures = "0.3" 与 tokio 1.x（macros / rt）；buffer_unordered 把在途任务数卡在 n。

```rust
use futures::stream::{self, StreamExt};

#[tokio::main]
async fn main() {
    let mut st = stream::iter(1..=5)
        .map(|n| async move { n * n })
        .buffer_unordered(2); // 最多同时推进 2 个
    while let Some(v) = st.next().await {
        println!("{v}");
    }
}
```
