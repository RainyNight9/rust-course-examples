## 镜 08 · env::args 返回迭代器（P15 02:24）

归类：教学摘录，非完整程序。

> 注意 cargo run -- 后面的参数才是传给程序的，不是给 Cargo 的。

```rust
use std::env;

fn main() {
    let args: Vec<String> = env::args().collect();
    let query = &args[1];
    let file_path = &args[2];
    println!("搜索 {query}，文件 {file_path}");
}

$ cargo run -- rust poem.txt
```

        Ok(Config {
            query: args[1].clone(),
            file_path: args[2].clone(),
            ignore_case: env::var("CASE_INSENSITIVE").is_ok(),
