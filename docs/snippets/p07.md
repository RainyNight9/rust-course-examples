## 镜 09 · 两个省事语法（P07 02:36）

归类：教学摘录，非完整程序。

> 注意 ..user1 会移动 String 字段，之后 user1 里被移动的字段就不能用了。

```rust
fn build_user(username: String) -> User {
    User {
        active: true,
        username,          // 字段初始化简写
        sign_in_count: 1,
    }
}

let user2 = User {
    username: String::from("bob"),
    ..user1             // 其余字段从 user1 移动过来
};
```

## 镜 20 · 没有 self 的那些函数（P07 05:34）

归类：教学摘录，非完整程序。

> 一个类型可以有多个 impl 块；Self 指代当前 impl 的类型。

```rust
impl Rectangle {
    fn square(size: u32) -> Self {
        Self { width: size, height: size }
    }
}

let sq = Rectangle::square(10);
```
