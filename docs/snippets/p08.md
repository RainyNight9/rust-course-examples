它们是命令行、配置、控制台输出、第三方依赖示例或教学语句摘录，**不是可独立编译的程序**。

## 镜 10 · Rust 没有 null（P08 02:54）

归类：教学摘录，非完整程序。

> Option 和它的变体在预导入模块里，不需要写 Option:: 前缀就能用。

```rust
enum Option<T> {
    Some(T),
    None,
}

let some_number = Some(5);
let absent: Option<i32> = None;
```

## 镜 13 · 必须穷尽所有可能（P08 03:40）

归类：教学摘录，非完整程序。

> 分支里可以直接绑定变体携带的数据，比如这里的 state。

```rust
fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => 1,
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter(state) => {
            println!("来自 {state:?} 的 25 分币");
            25
        }
    }
}
```

## 镜 16 · _ 和 other（P08 04:28）

归类：教学摘录，非完整程序。

> _ 匹配但不绑定值；other 会把值绑到变量上供分支使用。

```rust
let dice = 9;
match dice {
    3 => add_fancy_hat(),
    7 => remove_fancy_hat(),
    other => move_player(other),
}

match some_value {
    Some(x) => println!("拿到 {x}"),
    None    => println!("什么都没有"),
}
```

## 镜 18 · if let 与 let else（P08 05:01）

归类：教学摘录，非完整程序。

> if let 是语法糖，仍可搭配 else；代价是放弃了穷尽检查。

```rust
if let Some(3) = config_max {
    println!("最大值被设为 3");
}

let Some(x) = some_option else {
    return;      // 不匹配必须提前离开
};
println!("{x}");
```
