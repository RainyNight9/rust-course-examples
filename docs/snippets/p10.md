## 镜 13 · &v / &mut v / into_iter（P10 03:34）

归类：教学摘录，非完整程序。

> 遍历时不能同时修改同一个 Vec，编译器会拒绝。

```rust
for i in &v { println!("{i}"); }

for i in &mut v { *i += 50; }   // 解引用后修改

for i in v { println!("{i}"); } // v 被消耗
```
