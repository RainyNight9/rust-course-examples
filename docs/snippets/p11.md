# P11 · panic! 与 Result — 讲解摘录

对应 第 9 章 错误处理。以下片段按视频顺序保留原样，
它们是命令行、配置、控制台输出、第三方依赖示例或教学语句摘录，**不是可独立编译的程序**。

## 镜 06 · 展开还是直接终止（P11 01:47）

归类：教学摘录，非完整程序。

> release 构建常把 panic 设成 abort，配合系统服务减少清理开销。

```rust
fn main() {
    panic!("这里出了无法继续的问题");
}

// 命令行查看调用栈
$ RUST_BACKTRACE=1 cargo run
```

## 镜 07 · 发布版直接终止（P11 02:02）

归类：配置 / 输出片段。

> panic = "abort" 跳过展开清理，产物更小、行为更简单。

```toml
# Cargo.toml
[profile.release]
panic = "abort"
strip = true

# 命令行：用 release 产物验证，别用 cargo run
# cargo build --release
# ls -lh target/release/xxx
```

## 镜 12 · unwrap 与 expect（P11 03:26）

归类：教学摘录，非完整程序。

> unwrap 的默认报错信息很难定位，正式代码优先 expect 或显式处理。

```rust
let f = File::open("hello.txt").unwrap();

let f = File::open("hello.txt")
    .expect("hello.txt 应该随项目一起提供");
```
