## 镜 16 · 模式可能匹配不上吗（P21 04:23）

归类：教学摘录，非完整程序。

> 错误提示会直接建议你改用 if let 或 match。

```rust
let x = 5;                       // 不可反驳，OK
// let Some(x) = some_option;    // 编译错误

if let Some(x) = some_option {  // 可反驳，交给 if let
    println!("{x}");
}
while let Some(item) = stack.pop() { /* ... */ }
```

## 镜 19 · 一份速查表（P21 05:13）

归类：教学摘录，非完整程序。

> .. 只能忽略剩余字段，不能写在中间造成歧义。

```rust
match x {
    1 | 2 => println!("一或二"),
    3..=7 => println!("三到七"),
    Some(v @ 1..=5) => println!("小数值 {v}"),
    Point { x, .. } => println!("只关心 x = {x}"),
    _ => (),
}

match num {
    Some(n) if n < 0 => println!("负数"),
    Some(n) => println!("{n}"),
    None => (),
}
```
